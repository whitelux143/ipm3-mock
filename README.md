# 知的財産管理技能検定3級 模擬テスト（個人学習用）

スマホ（iPhone縦画面）向けの学習アプリです。`index.html` 1ファイルで動き、外部API・ログインは不要です。

- 学科 問1〜30（3択）／実技 問1〜30（○×＋理由、3択、金額入力、穴埋め）
- モード：①模擬試験 ②範囲別練習 ③間違い復習
- 学習履歴・途中回答・復習登録はブラウザの localStorage に保存（端末ごと）

## 開き方
GitHub Pages を有効にすると `https://whitelux143.github.io/ipm3-mock/` で開けます。
iPhoneのSafariで開き、共有ボタン →「ホーム画面に追加」でアプリのように使えます。
